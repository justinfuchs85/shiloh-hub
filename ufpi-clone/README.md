# UFP Industries — React Clone

A React.js clone of [ufpi.com](https://ufpi.com) (UFP Industries), built with Vite + React.

## Stack

- **React 18** + **Vite 5**
- Plain CSS (component-scoped)
- Google Fonts: Montserrat + Open Sans

## Sections

| Section | Description |
|---|---|
| **Navbar** | Fixed top nav, transparent → white on scroll, dropdown menus, mobile hamburger |
| **Hero** | Full-viewport dark blue hero with tagline and CTA buttons |
| **Business Segments** | Three cards: UFP Retail Solutions, UFP Construction, UFP Packaging |
| **Stats Bar** | Animated counters — 15,000+ employees, 200+ facilities, etc. |
| **About** | Company story, founding year, pillars of culture |
| **Investors** | Dark section with financial metrics (NASDAQ: UFPI) |
| **News** | Featured press release + sidebar list of recent announcements |
| **Careers** | Perks grid + call-to-action |
| **Footer** | Multi-column link footer with social icons |

## Getting Started

```bash
cd ufpi-clone
npm install
npm run dev
```

Then open `http://localhost:5173`
